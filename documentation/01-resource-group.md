# 📦 Creating the Resource Group

## Objective

The first step in building the Azure Administration Lab was creating a Resource Group.

Resource Groups provide logical organization for Azure resources and allow administrators to manage related services together.

## Configuration

| Setting | Value |
|---------|-------|
| Subscription | Azure subscription 1 |
| Resource Group | rg-windows-soc-lab |
| Region | East US |

## Why This Matters

Using a Resource Group simplifies:

- Resource organization
- Access management
- Cost tracking
- Resource deployment
- Resource cleanup
